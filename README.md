\# Iris Dataset Analysis



\## Description

This project uses Python and Pandas to study Iris flower data.



\## Tools

\- Python

\- uv

\- Pandas

\- Jupyter Notebook

\- Google Colab

\- Matplotlib



\## Dataset

The dataset has 150 flowers and 3 flower types.



\## Analysis

\- Show the first 5 rows.

\- Check missing data.

\- Find the average values.

\- Count flower types.

\- Create charts.



\## Results

\- No missing data.

\- Each flower type has 50 flowers.

\- Virginica has the longest petals.

\- Setosa has the shortest petals.



\## How to Run

1\. Install uv.

2\. Run `uv sync`.

3\. Run `uv run jupyter notebook`.

4\. Open `iris\_analysis.ipynb`.
